# PHUTTI ROBOT CAMP 2569

เว็บไซต์หน้าแรกภาษาไทยสำหรับค่ายหุ่นยนต์ PHUTTI ROBOT CAMP 2569 ออกแบบตามภาพต้นแบบ ธีมน้ำเงิน–ม่วง พร้อมรองรับหน้าจอมือถือ

## โครงสร้าง

- `dist/index.html` — หน้าเว็บและเมนูภาษาไทย
- `dist/style.css` — รูปแบบและการแสดงผลตามขนาดหน้าจอ
- `dist/app.js` — เมนูมือถือและหน้าต่างข้อมูล
- `dist/assets/robot-arena.webp` — ภาพสนามและหุ่นยนต์
- `.openai/hosting.json` — ข้อมูลเว็บไซต์เดิมบน Sites

## เปิดใช้งานในเครื่อง

ต้องมี Python 3 จากนั้นรันที่โฟลเดอร์ repository:

```sh
python -m http.server 8000 --directory dist
```

เปิด http://localhost:8000 ในเบราว์เซอร์ ไม่ต้องติดตั้งแพ็กเกจหรือ build

## นำไปใช้บนโฮสติ้ง

ใช้ `dist` เป็นโฟลเดอร์เว็บราก (publish/output directory) เว็บไซต์นี้เป็น HTML, CSS และ JavaScript แบบ static โดยอ้างอิงไฟล์จากรากโดเมน หากโฮสต์ภายใต้ subpath ต้องปรับเส้นทางไฟล์ให้ตรงกับปลายทาง

เว็บไซต์บน Sites: https://phutti-robot-camp-2569.panusddn.chatgpt.site
สิทธิ์เข้าถึงเว็บไซต์ขึ้นอยู่กับการตั้งค่าใน Sites การอัปโหลด repository นี้ไม่ได้เปลี่ยนสิทธิ์หรือเปิด GitHub Pages โดยอัตโนมัติ

## สถานะการทำงาน

- หน้าแรก เมนูมือถือ และหน้าต่างข้อมูลใช้งานได้
- กำหนดการ กติกาฉบับยืนยัน และผลการแข่งขันยังรอข้อมูลจากผู้จัด
- ระบบเข้าสู่ระบบ บันทึกผล และผลการแข่งขันสดยังไม่ได้เชื่อมต่อระบบหลังบ้าน
- ฟอนต์ Kanit และ Sarabun โหลดจาก Google Fonts พร้อมฟอนต์สำรอง

ไฟล์ภาพประกอบถูกสร้างขึ้นสำหรับเว็บไซต์นี้
